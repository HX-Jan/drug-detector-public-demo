# 初版功能范围

初版以触屏一体机的检测闭环为主线。参考材料由三份说明与两段设备演示组成；原始材料仅在本地审阅，不属于公开仓库内容。视频采用关键时间点抽帧核对，未对每一帧或每个操作作等价复刻。

## 材料差异与本版选择

| 项目 | 材料中的差异 | v0.1 选择 |
| --- | --- | --- |
| 终端 | 手机应用与一体机触屏 | Android 为主，电脑入口便于展示 |
| 浓度单位 | ng/mL 与 ng/L | 统一 ng/L，不混用或自动猜测转换 |
| 反应时间 | 10–30 分钟与 5/10 分钟 | 使用一体机的 5/10 分钟；默认 5 秒演示加速 |
| 连接 | 蓝牙与 U 盘电化学工作站 | 独立 Workstation 接口，初版仅模拟 |
| 导出 | TXT 与 Excel | 真正的 XLSX，含汇总与原始合成采样点 |
| 品类 | 吗啡、可卡因、大麻等不同列表 | 一体机列表中的四种类型 |
| 标曲 | 说明涉及相邻峰电流差；视频包含标定操作 | 实现差值拟合；先输入已获得的标定电流，未实现硬件逐点采集 |

## 实现状态

| 功能 | 状态 | 可检查的行为 |
| --- | --- | --- |
| 检测引导 | 已实现 | 不允许跳步，倒计时结束才可继续，支持取消 |
| 连接检查 | 模拟已实现 | 首页可连接/断开，断开时禁止开始 |
| 检测信号 | 合成 | 可重复的 101 点曲线，按正向峰取值 |
| 浓度换算 | 已实现数学计算 | 保留未经截断的计算值；区间外单独标注 |
| 标准曲线 | 已实现数学计算 | 5–10 点，实际计算 k、b、r；Android 持久保存 |
| 历史记录 | 已实现 | Android SQLite、电脑文件，详情保留当次标曲快照 |
| Excel 导出 | 已实现 | 多选导出，两张表，均带模拟来源标记 |
| 时间与电量 | 部分实现 | 系统当前时间；Android 读取运行终端电量，无硬件电量协议 |
| 实体扫码 | 待接入 | 当前为人工确认电极，不伪装扫码成功 |
| 厂家校正权限 | 待设计 | 演示标曲页面不设置虚假的“厂家密码” |
| BLE / USB 通信 | 待接入 | 无私有命令、密钥或真实连接实现 |
| 自动 LOD、SWV | 未实现 | 不以按钮或合成性能值替代真实能力 |
| 真样验证与设备兼容 | 待验证 | 编译通过不能证明硬件可用或检测有效 |

此版本完成“可审阅、可运行的公开基础源码”。参赛材料应按本表描述完成情况；对真实硬件的能力应另提供可公开的独立证据。
