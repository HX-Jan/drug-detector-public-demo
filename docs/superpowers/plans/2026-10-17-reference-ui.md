# 交互界面说明1 实施计划

目标：以本地文档中的截图和操作顺序为依据，修改电脑端与 Android 端，并为新增逻辑和关键原有逻辑添加中文注释。

设计：保留原生 Swing / Android View，统一白底、蓝色主按钮、灰色描边、顶部时间及返回入口。标曲编辑采用五个带蓝色下划线的标签页；底部按钮固定，参数区域可滚动；数值和英文名使用居中触屏键盘。参考照片的偏色、倾斜、遮挡及示例数值不作为软件样式或计算结果。

1. [x] 核心：新增完整标曲记录、参数校验、三次重复采集、基线确认、至少两个浓度点拟合、十次 LOD 统计、持久化及 JSON/XLSX 导出；原检测结果算法保持兼容。
2. [x] 两端：设备扫描、选中、连接、连接完成页；样品选择来自保存的标曲；管理员模式独立开启；列表支持选中、添加、修改和确认删除。
3. [x] 两端：共用五步标曲流程控制器，原生呈现信息、活化、曲线、LOD/LOQ、导出页与曲线查看器，避免两端功能漂移。
4. [x] 验证：核心验收覆盖已知统计值、非法输入、修改后失效、重启保存、删除、导出文件；两端自动操作完整流程并生成截图，核对正常和紧凑尺寸。
5. [x] 更新运行说明、截图对照、功能边界和验收记录。保留工作区已有的 Gradle wrapper 修改。

关键约束：信号明确标记模拟；pg/mL 与 ng/L 数值相等；LOD = 2.82 × 样本标准差，LOQ = 4 × LOD，按截图公式；保存成功才更新样品选择；导出取消或无 U 盘时不得提示成功；真实硬件协议不在现有材料中，继续使用模拟接口。
