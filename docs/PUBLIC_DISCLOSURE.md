# 公开版本说明

本仓库是根据功能材料独立编写的演示实现，当前版本为 1.1.0。它展示软件结构与基本流程，不是原设备源码的脱密副本。界面依据演示视频复现，仍有明确的功能差异，详见 UI_REFERENCE.md。

AI 部分公开 Java 服务接口、输入输出约定、规则模拟适配器及界面/存储实现；没有使用老师的模型源码、权重或训练数据。当前仅模拟调用流程并计算波形特征，尚未接入训练模型或私有服务，不生成分类答案与置信度。真实模型可在私有环境实现适配器，接入要求见 AI_INTEGRATION.md。

公开内容包括新写的 Java 代码、构建配置、测试、合成样例与说明。原始文档、原始演示视频、私有源码、厂家协议、真实样品数据、账户凭据、签名私钥以及本机 SDK 路径不上传。

仓库中的信号与默认标曲均为数学构造，结果统一标注模拟。没有已验证的检出限、选择性、回收率、准确度或合格阈值，不据此作真实检测结论。参赛时可按实际情况说明“公开版实现检测流程和数据处理，真实硬件模块未公开且未在此仓库验证”；不要将公开版描述成视频中设备的原始生产源码。
